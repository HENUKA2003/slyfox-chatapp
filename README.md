SlyFox Chat

A lightweight, terminal-based chat app built with Python and WebSockets. Runs directly from the Windows terminal (or as a standalone .exe) and lets two or more devices on the same LAN network chat with each other, with basic message encryption.

This was built as a fun side project to learn about WebSockets, real-time messaging, and simple encryption — not intended as a production-grade secure messenger.

Features
💬 Real-time messaging over your local network (LAN)
🔑 Per-contact secret key — changing the key instantly changes how the chat is encrypted/decrypted, so both sides need to use the same key to read messages correctly
👥 Group chat support
✅ Delivery status indicators (sent / delivered)
🎨 Retro terminal-style UI with colors and ASCII art
💾 Local chat history stored per contact/group
